# Maison Noir

###### "The House of Vigour"

Maison Noir is a luxury men’s fashion e-commerce platform built with Spring Boot and React. Designed for clarity, scalability, and masculine elegance.

## Tech Stack

### Frontend
- **Library:** React 19
- **Build Tool:** Vite 7
- **Styling & UI:** Tailwind CSS 4, Material UI (MUI)

### Backend
- **Framework:** Spring Boot 3.5.x
- **Language:** Java 24
- **Security:** Spring Security with JWT Authentication
- **Data Access:** Spring Data JPA (Hibernate), Spring Data MongoDB
- **Build Tool:** Maven

### Database
- **MySQL:** Relational data (Users, Addresses, Carts, Orders)
- **MongoDB:** Document data (Product Catalog & Variants)
